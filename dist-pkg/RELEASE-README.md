# 微信机器人 · 多人格/记忆版（增量版 & 精简版）

基于 Wechaty + puppet-xp + 本地 Ollama 的微信群聊/私聊 AI 机器人。

**本仓库只提供发行包下载，源码开发在私有仓库进行。**

## 两个版本怎么选

| | 增量版 (full) | 精简版 (lite) |
|---|---|---|
| 文字聊天（多条连发+emoji） | ✅ | ✅ |
| 长期记忆（模型无关） | ✅ | ✅ |
| 多人格切换（每群独立） | ✅ | ✅ |
| 定时主动发言 | ✅ | ✅ |
| 看图吐槽 | ✅（需 qwen2.5vl:7b + 6GB 显存） | ❌ |
| 附加组件（守护/诊断/实验脚本） | 部分 | 全部移除 |
| 适合 | 想要全部玩法、显卡达标 | 显卡弱/只想稳定聊天 |

## 下载

见右侧 **Releases** → 下载 `wechaty-bot-full.zip` 或 `wechaty-bot-lite.zip`。
包内含《安装与使用说明.md》（含完整注意事项），解压后先读它。

## 一分钟了解原理

机器人通过注入本机微信桌面客户端（3.9.10.27）收发消息，AI 用本地 Ollama 模型生成回复——聊天内容不出你的电脑。包里的 `patches/` 是对注入组件的手工修复（群消息收发和群名解析必需），安装时运行 `node scripts\apply-patches.mjs` 应用。
