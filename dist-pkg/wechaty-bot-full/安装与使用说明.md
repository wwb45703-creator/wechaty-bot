# 增量版（Full）安装与使用说明

微信群聊/私聊 AI 机器人：自动回复（支持多条连发+emoji）、长期记忆、多人格切换、看图说话、定时主动发言。全部本地运行，聊天内容不上传任何服务器。

> ⚠️ **先读注意事项**（文末），尤其是微信版本和账号风险两条。

## 一、环境要求

| 组件 | 要求 | 获取方式 |
|---|---|---|
| 操作系统 | Windows 10/11 | — |
| 微信桌面版 | **必须 3.9.10.27**，其他版本无法注入 | github.com/tom-snow/wechat-windows-versions/releases 下载 `WeChatSetup-3.9.10.27.exe` |
| Node.js | 18 或更高 | nodejs.org 下载 LTS 安装包 |
| Ollama | 任意近期版本 | ollama.com 下载安装 |
| AI 模型 | `ollama pull huihui_ai/qwen3-abliterated:8b`（文本，约5GB） | 命令行执行 |
| 看图功能（可选） | `ollama pull qwen2.5vl:7b`（约5.7GB）+ 6GB 显存显卡 | 命令行执行 |

显卡不达标可只跑文本模型（本包配置默认已分离文本/视觉模型）。

## 二、安装步骤

1. 解压本包到一个**非系统盘**目录（如 `D:\wechaty-bot`）
2. 安装微信 3.9.10.27 并登录（安装时可把路径改到非 C 盘；设置→关于微信→**关闭自动更新**——微信升级后机器人立即失效）
3. 安装 Node.js 与 Ollama，拉取上面两个模型
4. 在解压目录打开命令行，执行：
   ```
   npm install
   node scripts\apply-patches.mjs
   ```
   第二步**必须执行**：patches/ 里是对注入组件的手工修复，没有它群消息无法收发、群名全部为空
5. 复制 `config.example.json` 为 `config.json`，修改：
   - `rooms[0].topic`：改成你要服务的群名（和微信里显示的完全一致）
   - `proactive`：定时发言的群名和时间
   - `personas`：三张角色卡文案随意改
6. 杀毒软件（火绒/360 等）把解压目录和微信安装目录加入**信任区**——注入组件必被误报
7. 双击 `start.bat` 启动；看到"用户已登录 / 机器人已启动"即成功

## 三、使用速查

| 命令 | 效果 |
|---|---|
| `ding` | 存活测试（回 `dong`） |
| `菜单` | 功能列表 |
| 直接聊天 / 发图片 | AI 自动回复/看图吐槽 |
| `人设列表` / `变成喵酱` / `恢复默认` | 多人格切换（每群独立） |
| `我的记忆` / `忘记我` | 查看/清除 AI 对你的长期记忆 |

群聊默认"@它 或带唤醒词才回复"；私聊所有消息都回。定时发言在 `config.json` 的 `proactive` 里配置。

## 四、注意事项（重要）

1. **账号风险**：本项目通过注入方式接管微信桌面客户端，违反微信软件许可协议，存在被限制账号的可能。**强烈建议用小号**，不要在有大额资产/重要社交关系的账号上运行
2. **微信版本锁死**：3.9.10.27 是唯一适配版本。微信自动升级会使机器人失效，升级后需重新装回此版本
3. **杀毒误报**：Frida 注入组件几乎必被杀软拦截，信任区必须配置
4. **看图功能的图片来源**：机器人从微信本地缓存读取图片（自动发现数据目录+解密 .dat），仅处理本机文件
5. **隐私**：长期记忆（`memories/`）和聊天数据全部留在本机，本程序不向任何第三方发送聊天内容；但请遵守当地法规，勿用于骚扰、营销群发等场景
6. **显存**：6GB 显存可同时满足文本模型常驻；无独显的机器文本模型会部分走内存，回复变慢但可用

## 五、常见问题

- **群里 @ 不回复 / 群名全是空** → 补丁没应用，重新跑 `node scripts\apply-patches.mjs`
- **第一条回复要等十几秒** → 模型冷加载；本版已让文本模型常驻显存（keepAlive 2h），连续对话稳定在 1~3 秒
- **看图不回复** → 确认拉了 qwen2.5vl:7b；图片发出后等 5 秒（大图落盘有重试机制）
- **微信闪退** → 版本不对 / 杀软拦截注入
- **改了 config 不生效** → 重启机器人（关闭后重新 start.bat）
