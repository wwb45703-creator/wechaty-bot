# 精简版（Lite）安装与使用说明

微信群聊/私聊 AI 机器人（精简版）：自动回复（多条连发+emoji）、长期记忆、多人格切换、定时主动发言。全部本地运行。

> 与增量版的区别：**不含看图说话功能**（无需下载 5.7GB 视觉模型、无需独立显卡）、不含守护进程与实验性组件。核心聊天体验完全一致。

> ⚠️ **先读注意事项**（文末）。

## 一、环境要求

| 组件 | 要求 | 获取方式 |
|---|---|---|
| 操作系统 | Windows 10/11 | — |
| 微信桌面版 | **必须 3.9.10.27** | github.com/tom-snow/wechat-windows-versions/releases |
| Node.js | 18 或更高 | nodejs.org |
| Ollama | 任意近期版本 | ollama.com |
| AI 模型 | `ollama pull huihui_ai/qwen3-abliterated:8b`（约5GB） | 命令行执行 |

无独立显卡也能跑（模型部分走内存，回复稍慢）。

## 二、安装步骤

1. 解压本包到非系统盘（如 `D:\wechaty-bot`）
2. 安装微信 3.9.10.27 并登录（**关闭自动更新**）
3. 安装 Node.js 与 Ollama，拉取模型
4. 解压目录命令行执行：
   ```
   npm install
   node scripts\apply-patches.mjs
   ```
   第二步**必须执行**（群消息收发和群名解析依赖补丁）
5. 复制 `config.example.json` 为 `config.json`，改群名和角色卡
6. 杀软信任区加入解压目录和微信目录
7. 双击 `start.bat` 启动

## 三、使用速查

| 命令 | 效果 |
|---|---|
| `ding` | 存活测试 |
| `菜单` | 功能列表 |
| 直接聊天 | AI 自动回复（连发+emoji） |
| `人设列表` / `变成喵酱` / `恢复默认` | 多人格切换（每群独立） |
| `我的记忆` / `忘记我` | 查看/清除长期记忆 |

## 四、注意事项（重要）

1. **账号风险**：注入方式违反微信许可协议，有账号限制风险，**建议小号**
2. **版本锁死**：微信必须 3.9.10.27，自动升级会使机器人失效
3. **杀软误报**：信任区必须配置
4. **补丁必装**：`apply-patches.mjs` 不跑，群功能全废
5. **隐私与合规**：记忆和聊天数据只在本机；勿用于骚扰、群发营销

## 五、常见问题

- **群里 @ 不回复 / 群名空** → 补丁没应用
- **首条回复十几秒** → 模型冷加载；本版文本模型常驻显存 2 小时（keepAlive 2h）
- **改 config 不生效** → 重启机器人
