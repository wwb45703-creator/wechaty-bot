# 定向群聊、联网回答与认证边界（控制台 1.4.0）

本轮在 `D:\wechaty-bot` 现有代码上实现，微信版本、便携 Node 18、角色配置、已有记忆及旧 Key 均保留。没有下载模型、启用云端推理或付费搜索，也没有重做大型离线安装包。

## 消息范围

运行配置仅保留用户确认的两个固定群 ID；真实 ID 仅在忽略的 `config.json` 保存，不写入源码、示例或报告。`replyPolicy.allowedRoomIds` 与启用的房间配置同时匹配，名称仅展示。仅句首“小助手”、对机器人的提及或明确支持的命令触发。关闭私聊、普通消息全量回答、疑问触发、随机插话、欢迎及主动问候。

`reply-policy → admitMessage → processMessage → 发送前复核` 约束文本、搜索、知识库、插件、图片、链接与定时入口。其它群和私聊在模型、网络及消息状态写入前拒绝。已有发送失败不自动重投；只有收到发送确认才记录助手回复与成长。

puppet-xp 接收侧通常没有可靠的 mentionSelf 列表，兼容路径只匹配消息开头的完整 @昵称/群名片，拒绝正文提及、引用或相似名字。仍需用真实微信确认该适配器的 @元数据行为，隔离消息对象测试不能证明原生微信投递。

## AstrBot 状态

当前旧 Key 的实际结果为插件接口 200、知识库 403 缺少 `kb`、密钥管理接口 403。用户暂不能操作后台，因此没有创建新 Key、修改认证数据库或吊销旧 Key。

连接能力分开显示：插件可连接而知识库无权限时，服务仍在线，知识库计数为 `null`，界面持续显示缺 `kb`。401、403、网络不可达分别返回不同代码。认证与权限故障仅在凭据变化或手动重测后重新查询；普通状态轮询不会反复请求已拒绝的能力，日志仅记录状态变化。网络故障按 15/30/60 秒退避。

恢复步骤：在 AstrBot 后台创建授予 `plugin/chat/kb` 的专用 Key，保存到控制台“插件中心 → 连接与认证设置”，点击测试连接。不要把 Key 放在聊天或 Git 中。普通本地聊天、本地知识库与公开搜索不依赖外部知识库权限。

## 共用回答流程

普通文字和显式搜索均经 `ai.chat → research.prepare → 当前 Ollama 模型 → 最终文本质量检查`。两个群的普通聊天使用控制台选择的模型；AstrBot 只保留显式插件调用，生产自动桥接已关闭。

规则与独立的短 JSON 意图判断共同识别新闻、活动、陌生梗和简称；确定识别到的游戏名不会被模型的空字段擦掉。普通个人陈述保持本地，不因隐私过滤变成搜索故障。公开查询移除昵称、微信标识及会话信息，拒绝手机号、分组手机号、邮箱、凭据和私人内容；不向搜索服务发送记忆或完整上下文。

网络阶段最多 8 秒、3 个结果、2 篇正文，沿用统一的 DNS 复核、逐跳重定向校验、正文限量与取消控制。最后一个使用者取消时终止共用请求；其中一个使用者取消不会影响其他使用者。意图判断在本机执行，单独限时 5 秒。

活动/新闻优先近期官方页面；非官方资料需要不同域名相互印证。游戏名、区服及版本参与检查，也参与缓存键，防止缓存跨区服混用。未知发布时间、14 天前的消息、区服歧义或互相矛盾的活动日期不作为当前事实。发布时间与抓取时间分开保留，不能把“今天抓到”说成“今天发布”。

有效活动缓存 15 分钟、梗义 24 小时、失败 60 秒；相同查询合并，最多保留 256 项公开证据，可跨本地模型复用。每个群单独维护 12 条/10 分钟临时上下文，新增上下文不写磁盘；遗忘同时清理内存，并以持久删除代际防止另一进程遗忘后读出旧内容。

## 角色与模型

保留鹅王现有文案。身份、表达规则、短期群背景及外部证据分层。日常最多 50 字、1 至 2 句、单气泡，无 emoji、问句及嘲讽。功能命令的必要来源或参数输出独立处理。

最终清洗后检查内部重复、最近 5 次确认回复的近似重复、套话、规则回显、输入照抄与无来源数字。短句以精确重复为主，数字变化不直接当复读。最多重写一次，第二次仍不合格则不发送，记录质量拦截；不循环重试或补万能尾句。

| 模型类型 | 请求行为 |
| --- | --- |
| GPT-OSS | 按实际声明使用 `think:"low"` |
| Qwen3 | `think:false` |
| 其余聊天模型 | 省略不支持的 think 字段 |
| 原始 Prompt 模板的 MistralRP | Alpaca 序列保留角色、历史及当前输入，不改权重或名称；本机 Ollama 对其 JSON grammar 返回 sampler 400，故用受约束文本 JSON 并校验字段 |
| nomic-embed-text 等嵌入模型 | `/api/show` 能力校验后拒绝作为聊天模型，保留加载/卸载用途 |

默认温度 0.75、重复惩罚 1.10、上下文 8192，普通生成上限 160 token、GPT-OSS 1024 token。`ai.modelProfiles[模型名].options` 可覆盖参数，`jsonFormat` 可覆盖结构化采样兼容性。参考 [Ollama Chat](https://docs.ollama.com/api/chat)、[参数说明](https://docs.ollama.com/modelfile) 与 [MistralRP 作者说明](https://huggingface.co/Ttimofeyka/MistralRP-Noromaid-NSFW-Mistral-7B-GGUF/raw/main/README.md)。

## 复现与证据

`runtime/node18/node.exe scripts/verify-all.mjs` 是必须通过的离线门禁。新增 `directed-policy`、`astrbot-capabilities`、`online-integration`、`online-reply`、`research-flow` 测试覆盖边界、能力锁存、跨模型证据、缓存/取消、一次重写及遗忘。

`scripts/evaluate-online-models.mjs --live` 在临时数据根中串行使用真实本地模型和合成公开证据，不发微信、不写成长；完成后额外探测真实搜索与安全抓取。须先用项目三件套暂停机器人，测试、启停、打包串行执行。原始结果位于 `.test-artifacts/online-models/report.json`，首轮位于 `report-first-pass.json`。相关性统计只是启发式检查，不代表人工自然度评分。

控制台测试对话的“联网接话诊断”默认关闭；开启后展示检索状态、缓存、来源与发布时间，失败也保留诊断。它不会发送微信或写成长。真实 Chromium 验收使用 `scripts/test-console-renderer.mjs` 的隐藏隔离实例。

本轮最终测试数字、逐模型结果及上线状态见相邻 `ONLINE_REPLY_QA.md`。隔离测试和真实模型评测均不等同于真实微信收发确认。
